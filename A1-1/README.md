# Prompt Manager

Python을 활용하여 AI 프롬프트를 효율적으로 관리할 수 있는 콘솔(Console) 기반 프로그램입니다.

프롬프트를 추가하고, 목록을 조회하며, 카테고리별 조회와 검색 기능을 사용할 수 있습니다. 또한 자주 사용하는 프롬프트는 즐겨찾기로 등록하여 관리할 수 있습니다.

---

# 프로젝트 소개

GenAI를 활용하면서 생성한 다양한 프롬프트를 체계적으로 관리하기 위해 제작한 프로그램입니다.

Python의 기본 문법(변수, 조건문, 반복문, 함수, 클래스)을 활용하여 구현하였으며, Git과 GitHub를 이용하여 기능 단위로 버전을 관리하였습니다.

# 실행 방법

프로젝트를 다운로드한 후 터미널에서 실행합니다.

```bash
python main.py
```

※ 실행 파일명이 다를 경우 해당 파일명을 입력하면 됩니다.

---

# 프로그램 기능

## 1. 프롬프트 추가

새로운 프롬프트를 등록할 수 있습니다.

입력 항목

- 제목
- 내용
- 카테고리

등록된 프롬프트는 프로그램 실행 중 리스트에 저장됩니다.

---

## 2. 프롬프트 목록 조회

저장된 모든 프롬프트를 출력합니다.

출력 정보

- 번호
- 제목
- 카테고리
- 즐겨찾기 여부(★)

프롬프트가 없는 경우 안내 메시지를 출력합니다.

---

## 3. 카테고리별 조회

카테고리를 선택하면 해당 카테고리의 프롬프트만 출력합니다.

지원 카테고리

- 텍스트 생성
- 이미지 생성
- 영상 생성
- 페르소나
- 자동화
- 기타

---

## 4. 프롬프트 검색

키워드를 입력하면 제목 또는 내용에 포함된 프롬프트를 검색합니다.

검색 결과가 없는 경우 안내 메시지를 출력합니다.

---

## 5. 프롬프트 상세 보기

프롬프트 번호를 입력하면 상세 정보를 출력합니다.

출력 정보

- 제목
- 카테고리
- 내용
- 즐겨찾기 여부

잘못된 번호를 입력하면 오류 메시지를 출력합니다.

---

## 6. 즐겨찾기 관리

프롬프트 번호를 선택하여 즐겨찾기를 추가하거나 해제할 수 있습니다.

즐겨찾기는 ★ 표시로 확인할 수 있습니다.

---

## 7. 즐겨찾기 목록

즐겨찾기로 등록된 프롬프트만 출력합니다.

등록된 즐겨찾기가 없는 경우 안내 메시지를 출력합니다.

---

# 기본 프롬프트 데이터

프로그램 시작 시 기본 프롬프트가 등록되어 있습니다.

예시

- 이미지 생성 프롬프트
- 자동화 프롬프트
- 텍스트 생성 프롬프트

---

# 데이터 구조

각 프롬프트는 다음 정보를 포함합니다.

|속성|설명|
|---|---|
|title|프롬프트 제목|
|content|프롬프트 내용|
|category|카테고리|
|favorite|즐겨찾기 여부(True / False)|
