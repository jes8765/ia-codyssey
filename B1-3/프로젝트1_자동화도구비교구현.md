# 프로젝트 1. 자동화 도구 비교 구현

## 주제

컴퓨터활용능력 1급 모의시험 점수를 자동으로 분류하여 합격 여부를 판단하고, 결과를 기록 및 공유하는 자동화 워크플로우를 Make와 Zapier에서 각각 구현하였다.

Google Form을 통해 제출된 점수를 기준으로 조건 분기를 수행하였으며, 합격 여부에 따라 Google Sheets에 결과를 기록하고 Discord 채널에 알림을 전송하도록 설계하였다.

---

## 워크플로우 개요

본 프로젝트에서는 컴퓨터활용능력 1급 모의시험 점수 제출 과정을 자동화하였다.

사용자가 Google Form에 이름과 점수를 입력하여 제출하면 Trigger가 발생한다. 이후 제출된 점수를 기준으로 합격 여부를 판별하는 조건 분기를 수행한다.

점수가 70점 이상인 경우에는 합격 시트에 결과를 저장하고 Discord 채널에 합격 안내 메시지를 전송한다. 반대로 70점 미만인 경우에는 불합격 시트에 결과를 저장하고 Discord 채널에 불합격 안내 메시지를 전송한다.

동일한 구조를 Make와 Zapier에서 각각 구현하여 두 자동화 도구의 특징과 사용성을 비교 분석하였다.

---

# Make 구현

## 사용 서비스

* Google Forms
* Google Sheets
* Discord

## Trigger

Google Forms - Watch Responses

Google Form에 새로운 응답이 제출되면 자동화가 시작되도록 설정하였다.

## Router (조건 분기)

제출된 점수를 기준으로 다음과 같이 분기하였다.

* 점수 ≥ 70 : 합격
* 점수 < 70 : 불합격

## Action

### 합격 분기

* Google Sheets - Add a Row (합격자 시트 기록)
* Discord - Send a Message (합격 안내)

### 불합격 분기

* Google Sheets - Add a Row (불합격자 시트 기록)
* Discord - Send a Message (불합격 안내)

# 장단점 분석

## Make 장점

* 시각적으로 워크플로우를 확인할 수 있다.
* 복잡한 분기 구조를 설계하기 쉽다.
* 실행 흐름을 한눈에 파악할 수 있다.

## Make 단점

* 처음 사용하는 경우 인터페이스가 다소 복잡하게 느껴질 수 있다.

## Zapier 장점

* 단계별 설정 방식으로 사용이 쉽다.
* 비교적 빠르게 자동화를 구축할 수 있다.
* 초보자도 접근하기 용이하다.

## Zapier 단점

* 무료 플랜의 기능 제한이 존재한다.
* 복잡한 분기 구조를 구현할 경우 다소 불편할 수 있다.

# 최종 의견

동일한 자동화 워크플로우를 Make와 Zapier에서 각각 구현해 봄으로써 Trigger, Action, Filter의 역할을 이해할 수 있었다.

Make는 시각적인 워크플로우 구성과 다양한 분기 설계에 강점을 보였으며, 복잡한 자동화에 적합하다고 판단하였다. 반면 Zapier는 직관적인 인터페이스를 제공하여 자동화를 처음 접하는 사용자도 쉽게 사용할 수 있다는 장점이 있었다.

따라서 단순한 업무 자동화에는 Zapier가 적합하며, 다양한 조건 분기와 복잡한 흐름 설계가 필요한 경우에는 Make가 더 효과적인 도구라고 생각한다.
