# GameForge AI

AI를 활용하여 게임 아이디어를 구체적인 게임 기획으로 발전시키고, 게임 개발 과정에서 필요한 조언을 받을 수 있는 AI 기반 게임 개발 지원 웹 서비스입니다.

사용자가 게임의 장르, 특징, 플레이 방식, 시점, 분위기, 아트 스타일 등의 정보를 입력하면 AI가 이를 바탕으로 게임 기획서를 생성합니다.

또한 AI Mentor를 통해 게임 기획, 프로그래밍, Unity, Unreal Engine, UI/UX, 디버깅, 최적화 등 게임 개발과 관련된 질문을 하고 AI의 답변을 받을 수 있습니다.

> **배포 URL:** https://ia-codyssey.onrender.com

# 1. 프로젝트 소개

## 1.1 프로젝트 개요

### 프로젝트명

**GameForge AI**

### 프로젝트 목적

게임을 만들고 싶지만 아이디어를 구체적인 기획으로 발전시키기 어려운 사용자와 게임 개발 과정에서 도움이 필요한 개발자를 대상으로 AI를 활용한 게임 개발 지원 서비스를 제공합니다.

사용자가 자신의 게임 아이디어와 필요한 정보를 입력하면 AI가 이를 바탕으로 게임 기획서를 생성하고, 별도의 AI Mentor를 통해 게임 개발 과정에서 발생하는 질문에 대한 조언을 받을 수 있도록 구현했습니다.

## 1.2 기획 배경

게임을 만들기 위해서는 단순한 아이디어뿐만 아니라 장르, 핵심 게임플레이, 시스템, 플레이 방식, 타겟 사용자 등 다양한 요소를 구체적으로 정의해야 합니다.

하지만 게임 개발을 처음 시작하는 경우 이러한 요소를 혼자 정리하는 과정에서 어려움을 겪을 수 있습니다.

GameForge AI는 이러한 문제를 AI를 통해 보조하고, 사용자가 가지고 있는 아이디어를 실제 게임 기획으로 발전시킬 수 있도록 하는 것을 목표로 제작했습니다.

## 1.3 서비스 목표

- 게임 아이디어를 구체적인 게임 기획으로 발전시키기
- 게임 기획에 필요한 요소를 체계적으로 정리하기
- AI를 활용하여 게임 개발의 진입 장벽 낮추기
- 게임 개발 과정에서 필요한 조언 제공하기
- 실제 사용 가능한 AI 웹 서비스를 구현하고 배포하기

## 1.4 타겟 사용자

- 게임 개발을 처음 시작하는 사용자
- 게임 아이디어를 가지고 있는 예비 개발자
- 인디 게임 개발자
- Unity 및 Unreal Engine을 공부하는 개발자
- 게임 기획을 구체화하는 데 어려움을 겪는 사용자

# 2. 서비스 소개

## 2.1 서비스 한 줄 소개

> **게임 아이디어를 AI와 함께 실제 게임 기획으로 발전시키는 게임 개발 지원 서비스**

## 2.2 핵심 가치

GameForge AI는 사용자의 아이디어를 중심으로 AI가 부족한 게임 기획 요소를 구체화하도록 구성했습니다.

사용자가 입력한 정보를 바탕으로 게임의 핵심 시스템과 플레이 방식 등을 정리하여 하나의 게임 기획서 형태로 제공합니다.

또한 AI Mentor를 통해 게임 개발 과정에서 발생하는 다양한 질문에 대한 답변을 받을 수 있습니다.

## 2.3 주요 기능

### AI Planner

게임에 대한 정보를 입력하면 AI가 게임 기획서를 생성합니다.

생성되는 내용은 다음과 같습니다.

- 게임 개요
- 핵심 게임플레이
- 주요 시스템
- 플레이 루프
- 수익 모델
- 차별화 요소
- 개발 난이도
- AI Feedback

### AI Mentor

게임 개발과 관련된 질문을 입력하면 AI가 게임 개발 멘토의 관점에서 답변합니다.

### Resources

게임 개발 과정에서 참고할 수 있는 자료를 확인할 수 있습니다.

### 반응형 웹

데스크톱뿐만 아니라 모바일 환경에서도 서비스를 이용할 수 있도록 반응형 디자인을 적용했습니다.

# 3. 페이지 구성

## 3.1 Main

GameForge AI의 서비스와 주요 기능을 소개하는 메인 페이지입니다.

- Genre
- Game Features
- Game Mode
- Perspective
- Mood
- Art Style
- Platform
- Core Mechanics
- Game Concept
- Story
- Reference Games
- Additional Requests
