# GameForge AI 서비스 기획서

## 1. 서비스 개요

### 1.1 서비스명

**GameForge AI**

### 1.2 서비스 목적

GameForge AI는 사용자가 가지고 있는 게임 아이디어를 AI를 활용해 구체적인 게임 기획으로 발전시키고, 게임 개발 과정에서 필요한 질문에 대한 답변을 받을 수 있도록 지원하는 AI 기반 웹 서비스입니다.

게임 개발을 처음 시작할 때는 아이디어가 있어도 장르, 핵심 게임플레이, 주요 시스템, 플레이 방식 등의 세부 요소를 구체적으로 정리하기 어렵습니다.

GameForge AI는 이러한 과정을 AI가 보조하여 사용자가 자신의 아이디어를 보다 구체적인 게임 기획으로 발전시킬 수 있도록 하는 것을 목적으로 합니다.

### 1.3 기획 배경

게임 개발 과정에서 초기 아이디어를 실제 기획으로 발전시키기 위해서는 다양한 요소를 정리해야 합니다.

하지만 처음 게임을 만드는 사용자는 어떤 내용을 정리해야 하는지부터 어려움을 겪을 수 있습니다.

따라서 사용자가 기본적인 게임 아이디어를 입력하면 AI가 이를 바탕으로 게임의 주요 요소를 정리하고, 추가적으로 게임 개발과 관련된 질문도 AI에게 할 수 있는 서비스를 기획했습니다.

### 1.4 타겟 사용자

- 게임 개발을 처음 시작하는 사용자
- 게임 아이디어를 가지고 있는 예비 개발자
- 인디 게임 개발자
- Unity 및 Unreal Engine 등을 공부하는 개발자
- 게임 기획을 구체화하는 데 어려움을 겪는 사용자

---

## 2. 서비스 핵심 가치

GameForge AI가 제공하는 핵심 가치는 **게임 아이디어의 구체화와 게임 개발 과정에 대한 AI 지원**입니다.

사용자는 게임에 대한 기본적인 아이디어와 원하는 요소를 입력하고 AI Planner를 통해 게임 기획서를 생성할 수 있습니다.

또한 AI Mentor를 이용하여 게임 기획, 프로그래밍, Unity, Unreal Engine, UI/UX, 디버깅, 최적화 등 게임 개발 과정에서 발생하는 질문을 AI에게 직접 질문할 수 있습니다.

이를 통해 게임 개발을 시작하는 과정에서 필요한 기획과 정보 탐색을 하나의 웹 서비스에서 수행할 수 있도록 구성했습니다.

## 4. 핵심 기능

### 4.1 AI Planner

사용자가 입력한 게임 정보를 OpenAI API로 전달하고 AI가 이를 바탕으로 게임 기획서를 생성합니다.

#### 주요 입력 항목

- Genre
- Game Features
- Game Mode
- Perspective
- Mood
- Art Style
- Platform
- Core Mechanics
- Game Concept
- Story
- Reference Games
- Additional Requests

#### AI 출력

생성된 게임 기획서는 다음과 같은 내용을 포함합니다.

1. 게임 개요
2. 핵심 게임플레이
3. 주요 시스템
4. 플레이 루프
5. 수익 모델
6. 차별화 요소
7. 개발 난이도
8. AI Feedback

### 4.2 AI Mentor

사용자가 게임 개발과 관련된 질문을 입력하면 AI가 답변합니다.

질문할 수 있는 주제의 예시는 다음과 같습니다.

- 게임 기획
- 프로그래밍
- Unity
- Unreal Engine
- UI/UX
- 디버깅
- 최적화
- 게임 시스템 구현

### 4.3 Resources

게임 개발과 관련된 자료를 확인할 수 있도록 별도의 Resources 페이지를 구성했습니다.

### 4.4 반응형 웹

데스크톱뿐만 아니라 모바일 환경에서도 사용할 수 있도록 반응형 디자인을 적용했습니다.

화면 크기에 따라 다음 요소를 조정합니다.

- 헤더 및 네비게이션
- 로고 크기
- Hero 영역
- 이미지 크기
- 버튼 배치
- 콘텐츠 카드
- 여백 및 글자 크기

## 5. AI 기능 상세 설계

## 5.1 AI Planner 설계

### 입력

사용자가 게임의 기본적인 정보를 입력합니다.

```text
게임 장르
게임 특징
게임 모드
게임 시점
게임 분위기
아트 스타일
플랫폼
핵심 게임 메커니즘
게임 컨셉
스토리
참고 게임
추가 요청사항
```

### 처리

입력된 정보를 JavaScript에서 수집한 후 Flask 백엔드의 `/api/planner` 엔드포인트로 POST 요청을 보냅니다.

Flask 서버는 전달받은 데이터를 기반으로 OpenAI API를 호출합니다.

### 출력

AI가 입력된 게임 정보를 바탕으로 게임 기획서를 생성하고 Flask 서버가 결과를 JSON 형태로 반환합니다.

JavaScript는 반환된 결과를 웹페이지에 표시합니다.

### 사용자 가치

사용자가 가지고 있던 간단한 게임 아이디어를 게임 개요, 게임플레이, 시스템, 플레이 루프 등의 구체적인 기획 요소로 발전시킬 수 있습니다.

---

## 5.2 AI Mentor 설계

### 입력

사용자가 게임 개발과 관련된 질문을 텍스트로 입력합니다.

### 처리

JavaScript가 질문을 `/api/mentor` 엔드포인트로 POST 요청하고 Flask 서버가 OpenAI API를 호출합니다.

### 출력

AI가 게임 개발과 관련된 질문에 대한 답변을 생성하고 결과를 웹페이지에 표시합니다.

### 사용자 가치

게임 개발 중 발생하는 기술적 또는 기획적 질문을 AI에게 바로 질문하고 답변을 확인할 수 있습니다.

## 6. AI 요청 및 응답 구조

전체적인 AI 기능의 동작 과정은 다음과 같습니다.

```text
사용자
  ↓
HTML 입력 UI
  ↓
JavaScript
  ↓
fetch()
  ↓
Flask API
  ↓
OpenAI API
  ↓
AI 응답
  ↓
Flask JSON 응답
  ↓
JavaScript
  ↓
웹페이지 결과 표시
```

### API Endpoint

| Endpoint | Method | 역할 |
|---|---|---|
| `/api/test` | GET | 백엔드 연결 상태 확인 |
| `/api/planner` | POST | AI 게임 기획서 생성 |
| `/api/mentor` | POST | AI 게임 개발 답변 생성 |

## 7. AI 실패 처리 기준

AI 기능은 사용자가 정상적인 입력을 제공하지 않거나 API 호출 과정에서 오류가 발생할 수 있으므로 입력 검증과 예외 처리를 적용했습니다.

### 7.1 빈 입력

Planner에 요청 데이터가 전달되지 않은 경우 다음과 같이 처리합니다.

```json
{
  "error": "Request data is required"
}
```

Mentor에서 질문이 입력되지 않은 경우 다음과 같이 처리합니다.

```json
{
  "error": "Question is required"
}
```

### 7.2 API 오류

OpenAI API 호출 과정에서 예외가 발생하면 Flask 서버에서 오류를 처리하고 실패 응답을 반환합니다.

Planner:

```text
Failed to generate game plan
```

Mentor:

```text
Failed to generate mentor response
```

### 7.3 사용자 안내

필수 입력이 누락된 경우 사용자에게 입력이 필요하다는 내용을 안내하고, AI 처리 과정에서 오류가 발생한 경우 요청이 정상적으로 처리되지 않았음을 안내하도록 구성했습니다.

## 11. 반응형 설계

서비스는 데스크톱과 모바일 환경에서 모두 사용할 수 있도록 반응형으로 설계했습니다.

데스크톱에서는 콘텐츠를 넓게 배치하고, 모바일에서는 화면 너비에 맞춰 콘텐츠가 세로 방향으로 배치되도록 CSS를 조정했습니다.

특히 메인 페이지의 Hero 영역과 기능 카드, 헤더, 네비게이션 등의 요소가 모바일 화면에서 잘리지 않도록 크기와 간격을 조정했습니다.

개발 과정에서 실제 모바일 화면을 확인하면서 로고 및 Hero 이미지의 크기, 상단 네비게이션의 높이와 간격 등을 추가로 수정했습니다.

## 12. 배포 계획 및 결과

### 12.1 초기 배포 시도

과제 요구사항에 따라 처음에는 Vercel을 이용하여 Flask API를 배포하려고 했습니다.

그러나 Flask Serverless Function의 라우팅 과정에서 `/api/test`를 포함한 API 요청에 404 오류가 반복적으로 발생했습니다.

### 12.2 Render로 배포 방식 변경

문제를 해결하는 과정에서 Flask 서버를 직접 실행할 수 있는 Render Web Service 방식으로 배포 구조를 변경했습니다.

Render에서는 Gunicorn을 이용하여 Flask 애플리케이션을 실행하고 GitHub 저장소의 코드를 기반으로 자동 배포하도록 구성했습니다.

초기 배포에서는 `gunicorn: command not found` 오류가 발생했으며, `requirements.txt`에 Gunicorn을 추가하여 해결했습니다.

### 12.3 최종 배포

최종적으로 Render를 통해 웹 서비스를 배포했으며 실제 URL에서 주요 페이지와 AI 기능이 동작하는 것을 확인했습니다.

**배포 URL:** https://ia-codyssey.onrender.com

## 13. 보안 및 환경 변수 관리

OpenAI API Key는 코드에 직접 작성하지 않고 환경 변수로 관리합니다.

```text
OPENAI_API_KEY
OPENAI_MODEL
```

API Key가 GitHub 저장소나 공개 문서에 노출되지 않도록 관리하며, 배포 환경에서도 환경 변수로 설정합니다.

## 16. 프로젝트 결과

GameForge AI는 게임 아이디어를 AI를 통해 구체적인 게임 기획으로 발전시키고, 게임 개발 관련 질문에 대한 답변을 받을 수 있는 웹 서비스로 구현되었습니다.

HTML/CSS/JavaScript 기반의 프론트엔드와 Python Flask 기반의 백엔드를 연결하고 OpenAI API를 연동했습니다.

또한 반응형 웹을 적용하여 모바일 환경에서도 사용할 수 있도록 구성했으며, GitHub와 Render를 이용하여 실제 웹 서비스로 배포했습니다.

이번 프로젝트를 통해 AI 코딩 도구를 활용한 코드 생성뿐만 아니라 프론트엔드와 백엔드의 연결, API 연동, 환경 변수 관리, 배포 과정에서 발생하는 오류를 직접 확인하고 해결하는 경험을 할 수 있었습니다.
