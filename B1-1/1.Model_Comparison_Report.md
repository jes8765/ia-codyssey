# LLM 모델 비교·선정 보고서

## 1. 목표

휴머노이드 관련 논문 분석을 통한 논문 분석과 연구 동향 이해를 주제로 하여 해당 과업을 가장 잘 수행할 수 있는 LLM을 선정하는 것을 목표로, 논문 분석과 요약에 가장 유용한 AI를 선정하기 위한 문서

## 2. 비교 과업 정의


| 항목 | 내용 |
|--------|--------|
| 과업명 | 논문 분석 및 연구 아이디어 발굴 어시스턴트 |
| 과업 목적 | 연구 논문을 분석하여 핵심 기여, 기술적 한계, 연구 공백을 파악하고 후속 연구 아이디어를 도출한다. |
| 타겟 사용자 | 학부생, 대학원생, 연구자, 기술 조사 담당자 |
| 입력 데이터 형태 | 사용자가 제공한 논문 전문, 논문 요약(Abstract), 또는 논문 PDF |
| 출력 형식 | 논문 요약, 핵심 기여, 기술적 한계, 연구 공백, 후속 연구 아이디어 |
| 분석 범위 | 제공된 논문 내용에 기반하여 분석하며 근거 없는 추측은 하지 않는다. |
| 필수 산출물 | 핵심 기여(Key Contribution), 기술적 한계(Technical Limitation), 연구 공백(Research Gap), 후속 연구 아이디어(Future Research Idea) |
| 핵심 제약사항 | 논문에 없는 실험 결과, 수치, 결론을 임의로 생성하지 않는다. |
| 평가 목표 | 논문 이해력, 분석력, 종합적 사고 능력, 환각 억제 능력 및 연구 아이디어 생성 능력을 비교한다. |

## 3. 테스트 시나리오

사용자가 직접 선정한 최신 휴머노이드 로봇 보행 제어 관련 연구 논문 3편을

## 4. 비교에 사용한 동일 입력

모든 모델은 새로운 채팅 세션에서 동일한 프롬프트와 동일한 논문 자료를 제공받았다.

본 실험의 목적은 모델의 검색 능력이 아닌 논문 이해, 요약, 분석 및 연구 아이디어 생성 능력을 비교하는 것이다. 따라서 모든 모델에 동일한 휴머노이드 로봇 보행 제어(Humanoid Robot Locomotion Control) 분야의 연구 논문 3편을 직접 제공하였다.

## 5. 평가 축과 점수 산식

### 5.1 공통 채점 원칙

* 모든 평가는 예/아니오(Binary) 방식으로 판정한다.
* 각 평가 축은 5개의 체크 항목으로 구성한다.
* 해당 평가 축의 점수는 충족한 체크 항목 수로 계산한다.
* 충족 항목이 0개인 경우에도 최저 점수는 1점으로 기록한다.
* 각 체크 항목은 모델 응답 안에서 직접 확인 가능한 근거가 있을 때만 인정한다.
* 채점자의 추론이 필요한 경우는 불인정한다.
* 논문에 없는 실험 결과, 수치, 결론, 연구 성과를 생성한 경우 해당 항목은 불인정한다.

### 5.3 최종 점수 계산

각 모델의 최종 점수는 다음 식으로 계산한다.

```text
최종 점수 = 논문 이해 및 요약 정확성
          + 형식 준수
          + 공통 한계점 분석 능력
          + 연구 공백 도출 능력
          + 연구 아이디어 생성 능력
          + 환각 억제
````

최대 점수는 30점이며, 점수가 높을수록 본 과업 수행 능력이 우수한 것으로 평가한다.

### 8.2 Claude Sonnet 4.6을 최종 선정한 이유

정량 평가 결과에서 Claude Sonnet 4.6은 총점 29점으로 가장 높은 점수를 기록하였다. Gemini 3.1 Pro와 GPT-5.5 역시 각각 28점을 기록하여 성능 차이는 크지 않았으나, 본 과업의 핵심인 **논문 분석 및 연구 아이디어 발굴** 측면에서 Claude Sonnet 4.6이 가장 우수한 결과를 보여 최종 모델로 선정하였다.

첫째, **논문 내용에 대한 이해와 세부 정보 설명 수준이 가장 높았다.** Claude Sonnet 4.6은 단순히 핵심 기여를 요약하는 수준을 넘어 Transformer, DWL(Denoising World Model Learning), MPC/WBIC 등 각 논문의 주요 기술 요소를 구체적으로 설명하였다. 또한 논문별 한계를 기술할 때도 실제 논문에서 언급된 제한 사항을 상세히 정리하여 연구 내용을 보다 깊이 있게 이해하고 있음을 보여주었다.

둘째, **공통 한계점과 연구 공백을 가장 논리적으로 연결하였다.** 다른 모델들도 공통 한계점을 도출하였지만, Claude Sonnet 4.6은 시뮬레이션-현실 격차(Sim-to-Real Gap), 외부 감각 정보 미활용, 팔-다리 협응 부족 등 논문 간 공통 요소를 체계적으로 비교하였다. 또한 이러한 한계가 왜 연구 공백으로 이어지는지를 설명하여 단순 요약이 아닌 분석 중심의 결과를 제공하였다.

셋째, **후속 연구 아이디어의 근거가 가장 명확하였다.** Claude Sonnet 4.6은 제안한 연구 아이디어를 논문에서 확인된 한계와 직접 연결하였다. 예를 들어, 비전-보행 통합 연구는 외부 센서 활용 부족이라는 한계에서, 전신 협응 제어는 팔 제어의 부재라는 한계에서 출발하는 등 연구 아이디어의 타당성과 설득력이 높았다.

넷째, **환각(Hallucination) 발생 가능성이 가장 낮았다.** Gemini 3.1 Pro와 GPT-5.5는 일부 활용 가능성이나 상용화 전망에 대해 논문의 직접적 근거보다 확장된 해석을 포함한 반면, Claude Sonnet 4.6은 논문에서 확인 가능한 내용 중심으로 서술하였다. 따라서 사실 기반 분석이 중요한 연구 보조 업무에 더욱 적합하다고 판단하였다.

종합적으로 Claude Sonnet 4.6은 높은 정확성, 우수한 분석력, 논리적인 연구 공백 도출 능력, 그리고 안정적인 환각 억제 성능을 보여주었다. 따라서 본 과업인 **논문 분석 및 연구 아이디어 발굴 어시스턴트** 구축을 위한 최종 모델로 Claude Sonnet 4.6을 선정하였다.

## 9. 후속 활용 시 주의사항

본 실험은 동일한 논문 3편과 동일한 프롬프트를 사용하여 모델의 논문 분석 능력을 비교하는 것을 목적으로 수행되었다. 그러나 실제 연구 보조 업무에 활용할 경우 다음 사항을 고려해야 한다.

### 9.1 모델 출력의 비결정성(Non-determinism)

웹 기반 AI 서비스는 사용자가 temperature, top_p, max_tokens 등의 세부 생성 설정을 직접 제어할 수 없는 경우가 많다. 또한 서비스 업데이트나 모델 버전 변경에 따라 동일한 프롬프트를 입력하더라도 결과가 달라질 수 있다.

따라서 본 보고서의 평가 결과는 실험 시점 기준의 결과이며, 향후 동일한 모델을 사용하더라도 완전히 동일한 출력이 보장되지는 않는다.

### 9.2 연구 결과에 대한 최종 검증 필요

AI 모델이 생성한 논문 요약, 기술적 한계, 연구 공백 및 연구 아이디어는 참고 자료로 활용할 수 있으나 최종적인 연구 결론으로 사용해서는 안 된다.

특히 다음 항목은 반드시 사용자가 직접 논문 원문을 확인해야 한다.

* 실험 결과 및 성능 수치
* 연구 방법론의 세부 구현 방식
* 저자의 실제 결론 및 주장
* 논문의 제한 사항(Limitation)
* 인용 및 참고문헌 정보

### 9.3 환각(Hallucination) 가능성 존재

본 실험에서는 Claude Sonnet 4.6이 가장 우수한 성능을 보였으나, 모든 모델은 잠재적으로 환각(Hallucination)을 생성할 수 있다.

특히 다음과 같은 내용은 사실 여부를 반드시 검증해야 한다.

* 논문에 존재하지 않는 실험 결과
* 논문에 없는 수치 및 성능 지표
* 논문에서 직접 언급하지 않은 결론
* 논문 간 비교 결과에 대한 과도한 해석
* 상용화 가능성 및 산업 적용 전망

### 9.4 연구 아이디어의 검증 필요

AI가 제안한 후속 연구 아이디어는 연구 방향 탐색에 도움을 줄 수 있으나 실제 연구 가치가 검증된 것은 아니다.

따라서 연구 아이디어를 활용할 경우 다음 과정을 추가로 수행해야 한다.

1. 관련 선행 연구 조사
2. 기존 연구와의 차별성 검토
3. 구현 가능성 평가
4. 예상 기여도 분석
5. 연구 윤리 및 안전성 검토

### 9.5 입력 데이터 품질의 중요성

논문 분석 결과의 품질은 입력으로 제공되는 논문의 품질에 크게 영향을 받는다.

본 실험에서는 최신 휴머노이드 로봇 보행 제어 논문 3편을 사용하였으나, 실제 활용 시에는 다음 사항을 고려해야 한다.

* 최신 연구인지 여부
* 신뢰할 수 있는 학회 또는 저널 논문인지 여부
* 연구 분야의 대표성을 갖는지 여부
* 충분한 실험 검증이 이루어졌는지 여부

### 9.6 개인정보 및 저작권 고려

실제 연구 자료를 입력할 경우 개인정보 및 저작권 문제를 고려해야 한다.

* 공개되지 않은 연구 자료는 업로드 전 사용 가능 여부를 확인한다.
* 개인정보가 포함된 문서는 사전에 익명화 또는 마스킹을 수행한다.
* 논문 내용을 재배포하거나 인용할 경우 해당 논문의 저작권 및 인용 규정을 준수한다.
